Why won't my div center?

AK
Amara K. 2 hours ago

Put display: flex on the parent, then justify-content and align-items: center. Make sure the parent has a height!

JL
Jonas L. 1 hour ago

Also check you're styling the right element. The flex properties for centering go on the container, not on the thing you want centered. I lost an afternoon to that once, so now I always add a temporary outline to the parent to see how big it really is before I start moving things around.
