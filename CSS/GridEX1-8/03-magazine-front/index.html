Exercise 3 · Placing items by line number

Magazine front page

Place each story in an exact spot on a 4-column grid using grid-column and grid-row.

Your tasks (in style.css)

  1. Make .magazine a grid with 4 equal columns, two rows of 220px, and a 16px gap.
  2. .lead: from column line 1 to 3 and row line 1 to 3 (a 2 × 2 block in the top-left).
  3. .side-a: column lines 3 to 5, row 1. .side-b: column lines 3 to 5, row 2.
  4. .banner: the full width of the grid on row 3. Use a negative line number.
  5. Don’t place the four .brief-story items at all. Check where the browser puts them.

Bonus: Open DevTools, select .magazine and turn on the grid overlay with line numbers. Then move .lead to the right-hand side by changing only line numbers.

Hint

A 4-column grid has 5 column lines. 1 / -1 always means “first line to last line.” Rows you didn’t define (row 3 onwards) are created automatically with an auto height.
