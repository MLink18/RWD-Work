Exercise 1 · Your first grid

Photo gallery

Turn a plain list of photos into a tidy three-column gallery.

Your tasks (in style.css)

  1. Make .gallery a grid container.
  2. Give it three columns, each 250px wide, using grid-template-columns.
  3. Add a 20px gap between the photos.
  4. Give each .photo .swatch a height of 180px so the photos show up.

Bonus: The gallery hugs the left edge. Centre the whole grid inside .gallery with one property (it moves the grid, not the items).

Hint

Rows are created automatically, so you only need to describe the columns. For the bonus, look at justify-content.
