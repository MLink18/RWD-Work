Exercise 5 · grid-template-areas

Page layout with named areas

Draw a full page layout with strings, then rearrange it for small screens without touching the HTML.

Your tasks (in style.css)

  1. Give each part of .page a name with grid-area: header, nav, main, aside, footer.
  2. Make .page a grid with columns 200px 1fr 240px, rows auto 1fr auto, a 16px gap and a min-height of 80vh.
  3. Use grid-template-areas so the header and footer span all three columns, with nav, main and aside in the middle row.
  4. Add a media query for screens 700px wide or less: one column, everything stacked in this order: header, nav, main, aside, footer.

Bonus: Add a tablet layout (701px–1000px) with two columns, where the nav runs down the left side and the aside sits under main.

Hint

Each string is one row, each word is one column. Repeat a name to make it span. Inside the media query you only need to redefine grid-template-columns, grid-template-rows and grid-template-areas.
