Practice set

CSS Grid exercises

Eight exercises that follow the “Intro to CSS Grid” deck. Each folder has an index.html with the task brief and a style.css for you to work in.

To practise: using style.css, build the layout yourself. Colours and fonts come from shared/base.css, so you only write layout code. Compare your result with target.png in each folder.
