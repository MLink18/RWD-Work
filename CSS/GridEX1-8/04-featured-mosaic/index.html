Exercise 4 · span and auto-placement

Featured mosaic

Make some tiles bigger than others using span. You don’t say where the tiles go, only how big they are.

Your tasks (in style.css)

  1. Make .mosaic a grid with 4 equal columns and a 12px gap.
  2. Use grid-auto-rows so every row is 150px tall, including rows the browser creates.
  3. .wide tiles span 2 columns.
  4. .tall tiles span 2 rows.
  5. .big tiles span 2 columns and 2 rows.

Bonus: You’ll probably see empty holes in the mosaic. Add grid-auto-flow: dense to .mosaic and watch the smaller tiles fill the gaps. Then think about why this can be a problem for keyboard and screen-reader users.

Hint

grid-column: span 2 means “be 2 columns wide, wherever you land.” grid-template-rows only sizes the rows you list; grid-auto-rows sizes the rest.
