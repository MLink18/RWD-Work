Exercise 8 · Capstone

Calculator keypad

Put everything together: equal tracks, placement by line number, span and alignment. (It only needs to look right. No JavaScript.)

Your tasks (in style.css)

  1. Centre .calculator inside .stage using Grid.
  2. Make .calculator a grid of 4 equal columns, every row 72px tall, with a 10px gap.
  3. Make .display span the full width using line numbers, and make it taller than the buttons (96px works).
  4. Make the 0 key (.zero) two columns wide.
  5. Make the = key (.equals) two rows tall, so it fills the bottom of the right-hand column, beside the 0 row and the bracket row.
  6. Centre each key’s label inside the key with Grid.

Bonus: Rewrite the keypad layout with grid-template-areas instead of span. Which version is easier to read?

Hint

The HTML order matters: the = key comes right after ., so it starts on the 0 row and spans down into the last row. Look at where each key lands before you add the spans.
